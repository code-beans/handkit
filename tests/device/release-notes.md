## Downloads

| File | For |
| --- | --- |
| `handkit-test-nextui-*.zip` | Testing a TrimUI handheld with NextUI or MinUI: copy `Tools` to the SD card, run **Tools → Handkit Test** |
| `handkit-test-ports-*.zip` | Testing a handheld with knulli, muOS or another firmware with a ports menu |
| `sdl3-demo-*.zip` | The demo on its own, as a NextUI `.pak` |
| `sdk-minimal-*.zip` | The starter app, as a NextUI `.pak` |
| `sdk-input-check-*.tar.gz` | The input self-test program |
| `SHA256SUMS` | Checksums of the files above |

Each test zip contains a `README.txt` with install steps. The test writes `handkit-report.txt`; please attach it to a [device report](https://github.com/code-beans/handkit/issues/new?template=device-report.yml).
